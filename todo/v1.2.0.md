# v1.2.0

## dApp 连接（WalletConnect v2）

- [x] 集成 Reown WalletKit：Project ID 可在应用内配置（存金库），懒加载 SDK，解锁后初始化并恢复已连接会话
- [x] 顶栏「dApp」入口弹框：粘贴 `wc:` 连接串配对、已连接 dApp 列表（名称 / 网址 / 账户 / 链）、断开
- [x] 连接请求弹框：展示 dApp 信息与校验状态，选择暴露的钱包与网络，必需链未配置时明确提示
- [x] 请求审批弹框：eth_sendTransaction（解码 ERC-20 transfer / approve、无限授权与未知合约警示、手续费估算）、personal_sign / eth_sign、eth_signTypedData(_v4)、wallet_switchEthereumChain，逐条批准 / 拒绝，队列顺序处理
- [x] dApp 发出的交易写入交易记录（类型 dApp，备注 dApp 名称与方法），锁定时不签名、解锁后继续处理
- [x] 中继联调：用用户的 Project ID、钱包与模拟 dApp 两个独立进程走真实 WalletConnect 中继，配对 → 连接 → personal_sign → EIP-712 → 切链事件 → 断开全部通过
- [x] Project ID 内置为默认值（`frontend/web/.env` 的 VITE_WC_PROJECT_ID），旧金库解锁时自动补上，仍可在弹框里更换
- [ ] 真实网页 dApp 联调：用 Uniswap / PancakeSwap 走一遍连接、切链、approve、swap

## 观察钱包

- [x] 添加观察钱包：顶栏「添加观察钱包」弹框批量粘贴地址（校验 / 去重 / 选分组），只存地址不存私钥
- [x] 列表与编辑：名称前显示「观察」标签，转账 / 兑换 / 清空按钮禁用并提示原因，编辑弹框不显示私钥行，状态栏显示观察钱包数量
- [x] 批量操作与 dApp：一键清空 / 批量兑换自动跳过观察钱包并在提示里说明，dApp 连接不列出观察钱包，签名请求命中观察钱包时拦截
- [x] 升级：导入私钥时若地址已是观察钱包，直接补上私钥升级为普通钱包
