# v1.0.0

## 工程骨架

- [x] Tauri 2 工程（`src-tauri/`）+ Vite + Vue 3 前端（`frontend/web/`）
- [x] design tokens（`tokens.css`，浅 / 深主题，顶栏一键切换）
- [x] 基础公共组件：MxButton / MxInput / MxSelect / MxCheckbox / MxDialog / MxConfirm / MxMessage / MxTooltip / MxEmpty / MxSkeleton / MxTag / MxAddress / MxSpinner
- [x] 本地加密存储（口令 PBKDF2 派生密钥 + AES-GCM，Tauri store 落盘）+ 解锁页 / 锁定 / 重置
- [x] 系统托盘图标：菜单「显示窗口 / 退出」，左键单击恢复窗口，点关闭按钮收进托盘
- [x] 应用图标替换为用户提供的钱包图标（`app-icon.png`，`pnpm tauri icon` 生成 `src-tauri/icons/`）
- [x] 全站统一等宽字体（`--mx-font-family`，规则文件同步更新）
- [x] 用户自定义字体：顶栏「字体」弹框，预设列表（标注未安装）+ 自定义字体栈，即时生效存本机，可恢复默认

## 钱包

- [x] 私钥导入（支持多行批量，自动识别无效行、按地址去重，选分组）
- [x] 创建钱包（指定数量 1~200、分组）
- [x] 钱包分组（左侧栏新建 / 重命名 / 删除，钱包可单个改分组或批量移动）
- [x] 钱包列表（搜索、多选、余额展示、复制地址、编辑 / 查看私钥、删除、批量删除）
- [x] 同步 Token 余额：刷新时按当前网络的 Token 列表逐钱包查询，列表 Token 列显示非零 chip，悬停看全部

## 网络

- [x] 配置 RPC（网络增删改：名称 / RPC URL / chainId / 原生币符号 / Token 列表，RPC 一键检测，顶部切换）
- [x] 内置常用网络预设（Ethereum / BSC / Arbitrum / Base / Polygon，含 USDT / USDC）
- [x] Tauri 内 RPC 请求走 plugin-http，绕开 webview CORS

## 一键清空

- [x] 清空弹框：目标地址、勾选要清空的 Token 与原生币、先清 Token 再清原生币（扣除 gas）
- [x] 支持多钱包批量清空（并发 3），逐钱包显示状态与日志
- [x] 入口：顶栏按钮（选中则清空选中，否则清空当前列表全部）+ 行内单钱包清空
