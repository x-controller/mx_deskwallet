# v1.3.0

## 批量转账（一对多）

- [x] 链上方法：`batchTransfer` 从一个钱包按本地递增 nonce 连续广播多笔同资产转账，广播失败不占 nonce，全部广播后统一等回执
- [x] 弹框：选转出钱包与资产（默认 USDT）、收款列表每行「地址 金额」（空格 / 逗号分隔，没写金额的行用统一金额）、逐行格式校验与定位、合计与手续费估算（单笔 × 笔数）、余额校验、「填入列表钱包」一键把选中 / 当前列表的地址填进来、二次确认、逐笔状态
- [x] 入口：顶栏「批量转账」按钮（只选中一个可签名钱包时预选它）；交易记录类型「批量」，备注第几笔
- [x] 两套风格（经典 / Material 3 各自的 `components/batch/`）各写一份界面

## 聚合转账（多对一）

- [x] 链上方法：`collectFromWallet` 单钱包把一种资产转到目标地址，支持全部余额（原生币扣 gas）或固定数量，余额为 0 跳过、不足报错
- [x] 弹框：接收地址、资产（默认 USDT，下拉显示各资产合计）、全部余额 / 每钱包固定数量、打开时刷新各钱包余额并在进度列表显示可用余额、余额不足的钱包数提前提示、并发 3 执行、逐钱包进度与日志
- [x] 入口：顶栏「聚合转账」按钮（选中则作用于选中，否则当前列表全部，跳过观察钱包）；交易记录类型「聚合」
- [x] 两套风格各写一份界面
- [ ] 批量转账 / 聚合转账在测试网走一遍真实广播（目前只在浏览器里验证了表单解析、校验与两套界面）

## 顶栏二级菜单

- [x] 新增 `useMenu` 交互 composable 与 MxMenu / MdMenu 组件（图标触发 + 浮层列表，条目带图标 / 说明 / 禁用 / 危险色，靠右自动右对齐，键盘导航）
- [x] 顶栏按钮收成「添加钱包」（导入私钥 / 创建钱包 / 添加观察钱包）、「批量操作」（批量转账 / 聚合转账 / 兑换 / 一键清空，说明行显示作用范围）两个菜单；经典风格再把字体 / 深浅色 / 切换风格收进「更多」
